# Stochastic Finance Simulations

## Overview
This project implements stochastic process simulations and quantitative finance models using MATLAB. 
The analysis combines Brownian motion, Monte Carlo methods, stochastic differential equations, and option pricing techniques.

## Components
- Brownian Motion simulation
- Random walk and Gaussian increment processes
- Monte Carlo probability estimation
- Conditional expectation calculations
- Stochastic process path generation
- Ito Integral approximation
- Ornstein-Uhlenbeck process simulation
- Black-Scholes option pricing

## Methodology
The project applies stochastic modeling techniques and numerical simulations to study probabilistic behavior in financial systems and asset dynamics.

## Tools
- MATLAB
- Monte Carlo Simulation
- Brownian Motion
- Stochastic Differential Equations (SDEs)

## Key Findings
Monte Carlo methods and stochastic simulations successfully approximated theoretical probabilistic results and demonstrated the practical application of stochastic calculus in quantitative finance.
